# Contributing

Thank you for your interest in contributing to this project.

## Ways to contribute

- Report bugs and feature requests via GitHub Issues.
- Submit pull requests for improvements, documentation, or tests.
- Share research findings or reproducibility notes.

## Pull request workflow

1. Fork the repository.
2. Create a feature branch.
3. Make focused changes with clear commit messages.
4. Run the relevant validation checks.
5. Open a pull request with a short explanation of the change.

## Code and documentation standards

- Keep changes focused and well-documented.
- Update the README or docs when behavior changes.
- Add tests for smart contracts, backend logic, or reusable frontend logic when relevant.
